# nitro-unlock 1.2.0

Нативная утилита на Rust для Acer Nitro Lite 16 NL16-71G (Linux x86_64).
Временно выставляет Intel RAPL PSys PL1/PL2 на 70 Вт при запуске игры через Polkit;
игра запускается от обычного пользователя. Python больше не требуется.

**Предупреждение:** 70 Вт не подтверждены как безопасный заводской лимит.
Используйте только с исправным адаптером и охлаждением. Номинал ACPI не является
измерением фактически согласованной USB-PD мощности. Не используйте с адаптером,
который перегревается или отключается. Никакие аппаратные защиты не отключаются.

## Использование

Modrinth → Launch hooks → Wrapper command:

```text
/usr/bin/nitro-unlock /usr/bin/prime-run
```

Если PRIME не требуется, достаточно `/usr/bin/nitro-unlock`.
Не помещайте обёртку в Pre-launch command.

Steam:

```text
nitro-unlock %command%
```

Другие команды:

```sh
nitro-unlock --version
nitro-unlock --status
nitro-unlock --restore-stock
nitro-unlock /usr/bin/sleep 8
```

Лимиты восстанавливаются при завершении игры/обёртки, отключении адаптера,
CPU >=85 °C, устойчивом разряде аккумулятора >=5 Вт в течение 3 секунд или внешней
перезаписи PSys. Порог разряда — консервативная эвристика, а не измерение мощности БП.
Требуется ACPI-номинал адаптера >=100 Вт. При отмене авторизации игра запускается
без повышения. Внешние изменения лимитов не перезаписываются при откате.
Если один из исходных лимитов уже равен 70 Вт, он восстанавливается до 50 Вт
(совместимость с 0.1.1). `--restore-stock` явно выставляет оба лимита на 50 Вт.
Если root-процесс аварийно убит, откат не гарантирован; проверьте `--status`
и при необходимости выполните `--restore-stock`. Температура БП не измеряется.
Профили питания и Noctalia в этот проект не входят.

## Установка и сборка

[Releases](https://github.com/DenBroLiik/nitro-unlock/releases) ·
[Actions](https://github.com/DenBroLiik/nitro-unlock/actions)

Arch Linux (x86_64), из корня Git-репозитория:

```sh
makepkg
sudo pacman -U ./nitro-unlock-1.2.0-1-x86_64.pkg.tar.zst
```

Debian/Ubuntu (amd64), с Rust, `musl-tools`, `dpkg-deb` и установленной целью
`x86_64-unknown-linux-musl`:

```sh
rustup target add x86_64-unknown-linux-musl
./packaging/deb/build.sh
sudo apt install ./packages/nitro-unlock_1.2.0-1_amd64.deb
```

Тесты с имитацией sysfs (не изменяют настройки реального ноутбука):

```sh
cargo test --locked --offline
```

Для графической авторизации нужен агент Polkit. Устанавливается
`/usr/bin/nitro-unlock`; привилегированный worker всегда запускается из
установленного системного пути, не из пользовательского дерева исходников.

## Исходные замеры (Python-версия)

Minecraft, одна сцена: 38,12 FPS при 50 Вт и 59,79 FPS при 60 Вт.
На 70 Вт владелец наблюдал 70–80 FPS в движении и около 120 FPS на месте.
Это не новые замеры Rust-версии и не гарантия результата.
