# nitro-unlock

Префикс запуска для Acer Nitro Lite 16 NL16-71G с Linux. На время работы игры он выставляет PL1 и PL2 Intel RAPL PSys на 70 Вт. PSys задаёт общий бюджет питания платформы.

Обёртка запрашивает авторизацию через Polkit, проверяет модель ноутбука и наличие питания от сети, затем запускает игру от обычного пользователя. При завершении игры, отключении адаптера или температуре CPU 95 °C она возвращает исходные значения. Если на момент запуска один из лимитов уже вручную выставлен на 70 Вт, для него будет восстановлено штатное значение 50 Вт. При отмене авторизации игра запускается с текущим бюджетом.

## Установка

Скачайте пакет для своего дистрибутива со страницы [релизов](https://github.com/DenBroLiik/nitro-unlock/releases).

Arch Linux и производные

```bash
sudo pacman -U ./nitro-unlock-0.1.0-1-any.pkg.tar.zst
```

Debian 12 и новее, а также Ubuntu с Python 3.9+ и Polkit

```bash
sudo apt install ./nitro-unlock_0.1.0-1_all.deb
```

Оба пакета устанавливают команду в `/usr/bin/nitro-unlock`. Для графического запроса авторизации нужен агент Polkit в пользовательской сессии. На Arch с Niri обёртка запускает установленный `plasma-polkit-agent.service`, если он доступен. Из терминала `pkexec` может использовать текстовую авторизацию.

## Запуск

В Modrinth откройте настройки нужной сборки и перейдите в **Launch hooks → Wrapper command**. В это поле вставьте `/usr/bin/nitro-unlock`. Лаунчер передаст обёртке команду запуска Java. Поле **Pre-launch command** оставьте для разовых команд, которые завершаются до запуска Java.

Если в **Wrapper command** уже указан `prime-run` для NVIDIA, сохраните его после `nitro-unlock`.

```text
/usr/bin/nitro-unlock /usr/bin/prime-run
```

Настройки конкретной сборки имеют приоритет над общими. Запустите сборку и подтвердите запрос Polkit.

Короткая проверка из терминала

```bash
nitro-unlock --status
nitro-unlock /usr/bin/sleep 8
nitro-unlock --status
```

При ручном изменении лимитов до запуска игры можно вернуть оба значения к 50 Вт командой `nitro-unlock --restore-stock`. Посмотреть текущий бюджет и статус батареи можно через `nitro-unlock --status`. Показание номинала адаптера берётся из ACPI.

## Сборка из исходников

На Arch запустите `makepkg` в корне репозитория. Для Debian-пакета запустите `./packaging/deb/build.sh` в системе с `dpkg-deb`. По умолчанию архив Debian помещается в каталог `packages`.

Проверка запуска и отката на имитации sysfs выполняется командой `python3 tests/check.py`.

## Результаты замеров

На одной сцене Minecraft с теми же модами и шейдерами измерено 38,12 FPS при 50 Вт и 59,79 FPS при 60 Вт. На 70 Вт владелец наблюдал 70–80 FPS в движении и около 120 FPS на месте. Частота кадров и просадки зависят от сцены и сборки.
